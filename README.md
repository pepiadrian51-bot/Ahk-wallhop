# Roblox Rivals Wallhop & Macro Script (AHK v2)

A simple AutoHotkey v2 script for Roblox Rivals to toggle keybind macros.

## ## Features & Controls
* **`F1` — Dance 2 Clip**: Automatically opens your chat, types `/e dance2`, waits for the exact animation alignment, and perfectly triggers a sideways wall clip using simultaneous `W + Shift` inputs.
* **`F7` — Auto Clicker Optimizer**: Instantly boots up your OP Auto Clicker, automatically updates its internal speed to an optimized `11ms` setup, activates the clicker, and snaps your focus back inside the Roblox game window.
* **`F4` — Emergency exit**: Closes the script.

## ## IMPORTANT REQUIREMENT
For the `F7` Auto Clicker feature to work, you **MUST** download OP Auto Clicker and place it into your Windows **Downloads** folder. The file **MUST BE NAMED EXACTLY:** `AutoClicker (1).exe` *(including the space and the brackets, otherwise the script cannot locate or launch the program).*

## ## How to setup on Windows 11 (Manual Method)

This script is fully optimized and compatible with **Windows 11**. Follow these steps to run it:

1. Download and install **AutoHotkey v2** from the official website.
2. Go to your desktop, **Right-Click** on an empty space, and create a new AutoHotkey script.
3. Open the file by right-clicking it and selecting **Open with > Notepad (Notes)**.
4. Copy the entire code from `script.ahk` in this repository.
5. Paste the code into your Notepad file, save it, and change the file extension to `.ahk` if necessary.
6. Double-click the file to run the script!
