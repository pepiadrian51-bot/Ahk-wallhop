# Roblox Rivals Wallhop & Macro Script (AHK v2)

A simple AutoHotkey v2 script for Roblox Rivals to toggle keybind macros.

## Features & Controls
* **F2** - Toggle Wallhop Mode (`ON` / `OFF`)
* **F3** - Toggle Laugh Clip Mode (`ON` / `OFF`)
* **F4** - Emergency exit (closes the script)

### When Wallhop Mode (F2) is active:
* `Y` holds down `A`
* `X` holds down `Space`
* `C` holds down `Shift`
* `Arrow keys` perform automated mouse-flicks

### When Laugh Clip Mode (F3) is active:
* `Shift` automates the `Shift + S + Space` combination for 50ms
